    El que aprendràs

    Aprendràs a escriure codi com aquest, i a entendre'l:

    <!DOCTYPE html>
<html lang="ca">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>La meva pàgina</title>
    <link rel="stylesheet" href="estils.css">
  </head>
  <body>
    <!-- El contingut principal -->
    <main>
      <h1>Hola, món!</h1>
      <p class="avis">Aquesta pàgina l'he escrit jo.</p>
    </main>
  </body>
</html>
    /* estils.css */
h1 {
  color: teal;
}

.avis {
  padding: 1rem;
  border-left: 4px solid orange;
}
